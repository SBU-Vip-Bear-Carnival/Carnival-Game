# Wiring

Diagrams and photos of how the cabinet is actually wired.

**This must agree with `firmware/carnival/src/config/pins.h`.** If you move a
wire, update both in the same pull request. A pin map that only exists in
documentation is how the next person loses an afternoon to a fault that is not
there.

Photos of the real wiring are worth as much as a clean diagram — take them.
